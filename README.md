# 🧁 Bakecost – Recipe Pricing Tool for Pastry Chefs

Bakecost is a SaaS platform that helps pastry chefs calculate recipe costs including ingredients, labor, packaging and overhead.

This repo includes:
- UI mockups
- Architecture overview
- Example OCR output (JSON)
- Public-facing information (core app logic is private)

👨‍🍳 Built with: Lovable.dev, Figma, Make, Python, OCR, and chat GPT.

## 💡 Why Bakecost?

Most pastry chefs don't know how much their desserts accurate cost.  
They rely on guesswork or spreadsheets that are hard to maintain.  
Bakecost solves this with a clean interface, automatic ingredient detection (OCR), and supplier integration.

## ⚙️ Tech Stack

- 🧩 Lovable.dev (app logic, UI/UX)
- 🪄 Make.com (automations & webhooks)
- 🧠 AI + OCR (ingredient extraction)
- 📊 Google Sheets (supplier price feeds)
- 🎨 Figma (UX/UI design)
- 🐍 Python (backend prototype)
