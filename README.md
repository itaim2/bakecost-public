# 🧁 Bakecost – Recipe Pricing Tool for Pastry Chefs

Bakecost is a SaaS platform that helps pastry chefs calculate recipe costs including ingredients, labor, packaging and overhead.

This repo includes:
- UI mockups
- Architecture overview
- Example OCR output (JSON)
- Public-facing information (core app logic is private)

👨‍🍳 Built with: Lovable.dev, Figma, Make, Python, OCR, and chat GPT.
